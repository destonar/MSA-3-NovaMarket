# Описание

Здесь я немного отклонюсь от изначальных требований к сдаче хадания, потому что я решил проверить, что требуемая конфигурация `nginx` действительно заработает. Поэтому `compose.yaml` - это как раз таки compose проект, который проверяет это. Он поднимает 3 контейнера: `backend` (простейшее апи с единственным эндпоинтом `/ping`), `logistics` (то же самое апи) и `nginx` с конфигураций из `/nginx/nginx.conf`. Эта конфигурация как раз таки и объединяет обе требуемые в задании конфигурации в одну, где `backend` разделен на две локации с разными лимитами, а для `logistics` настроен circuit breaker.

Для тестирования выполняется `docker compose up`, после чего требуется остановить контейнер `logistics`. Трафик генерировался с помощью `locust` из предыдущего задания.
